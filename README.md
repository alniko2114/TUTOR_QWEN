# 📱 Тренажёр промптинга для QWEN

Интерактивный учебный тренажёр для обучения промптингу на примере QWEN.

## 🚀 Быстрый старт (локально в браузере)

### Вариант 1: Автономный HTML-файл (самый простой)

1. Откройте файл `public/autonomous.html` в любом браузере
2. Всё! Работает без сервера, без интернета, без установки

**Файл содержит:**
- ✅ Все 6 учебных разделов
- ✅ 18 практических заданий
- ✅ Встроенную песочницу с iframe chat.qwen.ai
- ✅ Тёмную/светлую тему
- ✅ Сохранение прогресса в localStorage

### Вариант 2: Собранный проект (PWA)

1. Откройте папку `dist/` в браузере через локальный сервер:
   ```bash
   # Python 3
   cd dist
   python -m http.server 8000
   
   # Или Node.js
   npx serve dist
   ```
2. Откройте http://localhost:8000
3. Приложение можно установить как PWA на Android/iOS

## 📱 Установка на Android

### Способ 1: PWA (без APK)
1. Разместите папку `dist/` на любом хостинге с HTTPS (Netlify, Vercel, GitHub Pages)
2. Откройте сайт в Chrome на Android
3. Нажмите «⋮» → «Добавить на главный экран»
4. Приложение появится как обычное

### Способ 2: APK через PWABuilder
1. Разместите сайт на хостинге (HTTPS обязательно!)
2. Перейдите на https://www.pwabuilder.com/
3. Введите URL → «Package for stores» → «Android»
4. Скачайте APK

### Способ 3: APK через Bubblewrap
```bash
npm install -g @bubblewrap/cli
bubblewrap init --manifest=https://ваш-сайт.ru/manifest.json
bubblewrap build
```

## 🛠️ Разработка

### Установка зависимостей
```bash
npm install
```

### Запуск dev-сервера
```bash
npm run dev
```

### Сборка для продакшена
```bash
npm run build
```

Результат будет в папке `dist/`

## 📋 Системные требования

**Для автономного HTML:**
- Любой современный браузер (Chrome, Firefox, Safari, Edge)
- Не требует сервера
- Не требует интернета (кроме iframe chat.qwen.ai)

**Для разработки:**
- Node.js 16+
- npm или yarn

## ⚠️ Ограничения

1. **iframe chat.qwen.ai** — QWEN может блокировать встраивание. Используйте кнопку «Открыть в новой вкладке»
2. **API-ключи** — хранятся в localStorage браузера пользователя
3. **HTTPS** — для PWA и Service Worker нужен HTTPS (кроме localhost)
